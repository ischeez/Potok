# Potok API

NestJS API для канбан-доски. Сервис использует PostgreSQL напрямую через `pg`, поэтому схема и запросы остаются прозрачными, а запуск не зависит от ORM-генерации.

## Команды

Из корня монорепозитория:

```bash
npm run db:migrate -w @potok/api
npm run db:seed -w @potok/api
npm run dev -w @potok/api
```

API доступен на `http://localhost:3001/api`, проверка состояния — `GET /api/health`.

Переменные окружения перечислены в `.env.example`. Команды автоматически читают `.env` из корня монорепозитория или из `apps/api`. Если файл отсутствует, API ожидает локальную базу `potok` с пользователем и паролем `potok`.

## Проверки

```bash
npm test -w @potok/api
```

Проверки DTO выполняются всегда. `npm run test:integration` из корня создаёт отдельную базу `potok_test`, применяет миграции и запускает интеграционные проверки. Suite удаляет только созданные им задачи.
