# Заметки о сдаче

Проверено локально 22 октября 2026 года. Репозиторий создан отдельно, ветка — `feat/kanban-board`.

## Соответствие заданию

| Требование | Реализация |
| --- | --- |
| Три колонки | «Новая», «В работе», «Готово» |
| Создание | Название, описание, приоритет; можно выбрать начальную колонку |
| Просмотр и редактирование | Диалог деталей и отдельный режим формы |
| Удаление | Подтверждение перед запросом к API |
| Перемещение | Drag and Drop на компьютере; меню статуса на всех устройствах |
| Сохранение после перезагрузки | PostgreSQL через NestJS REST API |
| Компьютер и телефон | Три колонки на широком экране, вкладки статусов на телефоне |
| Загрузка, ошибки, пустота | Skeleton, повторная загрузка, сохранение текста формы при ошибке, пустые колонки и доска |
| Миграции | Версионированный SQL, транзакции и advisory lock |
| Небольшое улучшение | Поиск по названию и описанию вместе с фильтром приоритета |

## Проверки

- Чистая установка через `npm ci` по закоммиченному lockfile.
- `npm run check`: ESLint, TypeScript, 5 API unit-тестов, 4 frontend unit-теста, сборка обоих приложений.
- `npm run test:integration`: 3 дополнительных сценария с настоящим PostgreSQL в `potok_test`; вместе с DTO suite проходят 8 тестов.
- `npm run test:e2e`: 15 браузерных проверок проходят. Один desktop drag-сценарий намеренно пропускается в мобильном проекте; перенос через меню проверяется на телефоне в полном CRUD-сценарии.
- Проверены ширины 320, 390, 768, 1024, 1440 и 1920 px.
- Миграция и seed запускаются повторно без повторного создания схемы и демонстрационных задач.
- Визуально просмотрены скриншоты компьютера и телефона.
- Отдельно запущены собранный NestJS и `vite preview`: задача создана через интерфейс и прочитана из PostgreSQL, ошибок выполнения в браузере нет.

Локальное окружение: macOS, Node.js 26, Chromium и PostgreSQL 17 в Docker. Минимальная заявленная версия Node — 22.12; workflow GitHub Actions настроен на Node 22. Сам workflow пока не выполнялся на GitHub, поскольку репозиторий ещё не опубликован.

## Что изменилось после проверки

Интеграционные тесты поймали важную деталь DTO: TypeScript создавал собственные поля со значением `undefined`, из-за чего частичный `PATCH` мог записывать лишние значения. Теперь обновляются только реально переданные поля; пустое обновление возвращает `400`.

Браузерный сценарий обнаружил отправку формы при переходе из просмотра к редактированию. У кнопок разные ключи и явные типы, переход отменяет стандартное действие клика. Редактирование, сохранение и перезагрузка проходят в обоих браузерных проектах.

После проверки мобильного скриншота исправлены ширина прогресса и отображение ручки перетаскивания на сенсорном экране. Импорты иконок сделаны адресными: сборщик обрабатывает около тысячи модулей вместо более чем одиннадцати тысяч.

Холодный запуск тестов выявил гонку готовности: Vite уже отвечал, пока NestJS ещё компилировался. Playwright теперь ждёт отдельно интерфейс и успешный `/api/health`, прежде чем открывать доску.

## Ограничения

Это одна доска без авторизации, живой синхронизации между вкладками, пагинации и офлайн-режима. При одновременном редактировании применяется последняя запись. Внутри колонки нет ручного порядка карточек. Удалённые задачи не восстанавливаются.

Для публичного сервиса нужны отдельная работа над авторизацией и инфраструктурой. Подробности запуска и решения описаны в корневом README.

## AI и время

AI участвовал в структуре проекта, визуальном оформлении, API, миграциях, тестах и документации. Проверка опиралась на реальные команды, базу и браузерные сценарии. Скриншоты сгенерированы из работающего приложения.

Около 30 минут активной работы с AI: параллельная подготовка API, сборка интерфейса, исправления по тестам и оформление репозитория. Время указано как оценка этой сессии.
